# Frame Gallery frontend

React Router (SPA mode), TypeScript, Tailwind CSS and shadcn/ui. The Electron shell for the desktop app is `main.js`.

```bash
pnpm install
VITE_API_URL=http://localhost:5055 pnpm dev
```

Brand guide and design tokens are in [`theme/`](theme/BRAND.md). Full setup, tests and builds are in [docs/development.md](../docs/development.md).
